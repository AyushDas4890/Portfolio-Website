# Cancer TF Atlas — "Discovery, in 3D" · Microscope · 8 s silent loop

Brief: intro film for a classifier that rediscovers cancer master-regulator transcription factors. Silent. 1920×1080, 24 fps, 8 s loop. Plate mode shows each real screen in a frosted panel over the tissue.

Style: microscope, adapted. The style asks for a licence-clean micrograph; none exists for this project, so the tissue is drawn procedurally as stained nuclei: illustrative, never presented as a real sample. Navy field `#07101F`, one accent yellow `#FFD23F`, Space Grotesk labels, frosted panels, a live scale bar.

## Three candidate structures
1. **Infinite dive** — log zoom: tissue → one cell → nucleus → a strand whose beads are TFs (GATA3, HNF1B, NKX2-1) → the beads become a new tissue. *Chosen*: a self-similar log zoom loops perfectly.
2. **Five tissues** — BRCA / KIRC / LUAD / PRAD / COAD panels each lighting its TF. Clear but static.
3. **Globe** — the product's 3D genome globe. Already a screenshot on the site.

## Beat sheet
| t | beat |
|---|---|
| 0–2.6 | Tissue; scale bar 100 µm; dive toward one cell lit yellow. |
| 2.6–5.0 | Cell fills frame; scale bar falls through 10 µm; frosted panel "98.76 % accuracy · 19 TFs". |
| 5.0–7.0 | Strand with three labelled beads: GATA3 · breast, HNF1B · kidney, NKX2-1 · lung. |
| 7.0–8.0 | Beads become nuclei of the next tissue; zoom is exactly one decade per loop, so t=8 = t=0. |
